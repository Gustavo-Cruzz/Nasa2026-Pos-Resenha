# Demo

1. Open Explore; select Rio Verde.
2. Enter three historical crops and optional soil.
3. Select one planting month; explain it is a common historical climate window, not a calendar prescription.
4. Open Results; compare global A/B/C, NASA provenance, qualitative indicators and explicit unknowns.
5. Explain Rio Verde ZARC adds regional context only; it is not field validation and raw codes are not percentages.
6. State: no forecast, yield, NPK, irrigation prescription, or field validation.
