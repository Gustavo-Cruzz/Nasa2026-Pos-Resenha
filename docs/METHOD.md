# Method

NASA POWER daily data: 2011-01-01–2025-12-31, UTC. Missing/sentinel values stay null. Monthly summaries use valid days only. Coverage is reported per parameter.

Engine: global locations return climate-only. Rio Verde uses only ZARC rows in `data/rio-verde-zarc.json`. Scores remain null when comparative evidence is missing. No yield, NPK, SOC, irrigation need, forecast, or field diagnosis is calculated.
