# Data artifact policy

`nasa-power-rio-verde.json` is a verified exact-coordinate NASA POWER fallback with provenance and hash in its metadata sidecar. It must never serve another coordinate.

`brazil-municipalities.json` is generated from the official IBGE minimum-quality municipal mesh and locality list. `brazil-zarc-index.json` is generated from the official MAPA 2026/2027 Tábua de Risco, filtered to the current P0 cultures and aggregated by municipality/crop. Rebuild both with:

```bash
SOURCE_ACCESSED_AT=YYYY-MM-DD npm run build:brazil-context -- /path/ibge-malha.json /path/ibge-localidades.json /path/zarc.csv
```

`ibge-2025-extra-municipality-features.json` contains the current official-mesh geometry missing from the minimum-quality API response. The current artifact adds Boa Esperança do Norte (code 5101837) from the official 2025 mesh; operational-area codes 4300001/4300002 in ZARC are recorded as unmatched and are not treated as municipalities. Generated documents retain source URLs, access date and input SHA-256. Do not hand-edit measurements, boundaries, risk codes or source rows. The original 233 MB ZARC CSV remains ignored because the auditable compact artifact is committed.

`npm run update:brazil-context` discovers the newest annual-safra CSV in the official MAPA CKAN package, downloads current IBGE API inputs, rebuilds both artifacts and deletes the temporary source files. The weekly/manual GitHub workflow runs this command and opens a reviewable pull request only when official artifacts change; it never deploys or merges data automatically.

`nasa-power-rio-verde.json` was recaptured on 2026-11-14 to include surface pressure (`PS`); its metadata sidecar carries the new hash. `data/ndvi/<site>.json` (+ `.meta.json`) are pre-processed MODIS MOD13Q1 NDVI series (collection v061, via the Microsoft Planetary Computer STAC catalog) for the seven exact demonstration coordinates (Rio Verde, Rio Verde campo, Sorriso, Luís Eduardo Magalhães, Cascavel, Accra and New Delhi), written only by `npm run fetch:modis-ndvi -- <site>` after a complete, validated download; they are read only when the SHA-256 and the exact coordinates match. Do not hand-edit them.

`data/ndvi-brazil/` is the national municipal MODIS NDVI artifact: one modelled 250 m interior point per IBGE 2025 municipality (5,571), with monthly climatology, coverage and status per municipality in `states/<UF>.json`. It is context for the municipality, not the farm. Read `data/ndvi-brazil/README.md` before running `npm run fetch:ndvi-brazil` or changing its files; they are checksum-verified and must not be hand-edited.

`data/soilgrids/` is the Brazil-wide SoilGrids production registry. Each reviewed artifact has exact-coordinate or reviewed-tile scope, its native 250 m support, 0–5 cm depth, conventional units, Q0.05/Q0.5/Q0.95 interval and a SHA-256 sidecar. Read `data/soilgrids/README.md` before generating or registering additional regional artifacts. Unprocessed coverage remains unknown; no artifact is extrapolated beyond its documented extent.

`data/soil/brazil-municipal-soil-v1.json` is the compact hackathon lookup generated by `npm run build:brazil-soil -- --execute` from official SoilGrids 2.0 mean rasters aggregated at 5 km. It combines 0–5, 5–15 and 15–30 cm at an interior reference point for each IBGE municipality. Complete coverage is 5,456/5,571 municipalities; remaining records stay unknown. It is not a municipal average or field measurement.

`data/soil/brazil-municipal-moisture-v1.json` is generated by `npm run build:brazil-moisture -- --execute` from NASA POWER monthly regional `GWETROOT`. It stores 2015–2025 monthly climatology and each grid cell's latest valid dated month through the build year. `GWETROOT` is a dimensionless modelled root-zone wetness fraction, not volumetric moisture, forecast or irrigation need.
