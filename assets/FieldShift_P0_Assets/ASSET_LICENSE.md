# Field Shift — autoria e proveniência dos assets P0

**Lote:** Field Shift P0 (2026-11-13).

Os PNGs de runtime foram elaborados especificamente para o Field Shift por meio de scripts de desenho procedural originais, usando a direção de arte informada pela equipe. As pranchas de prévia são ilustrações auxiliares, não dados científicos nem material de terceiros incorporado ao aplicativo.

Os scripts editáveis estão em `source/`. A equipe pode usar e modificar os arquivos no projeto observando os termos da plataforma empregada. Este registro informa proveniência, não equivale a assessoria jurídica nem assegura ausência de semelhanças involuntárias.

Os ícones de NASA e as camadas climáticas são representações gráficas abstratas; não constituem medições, previsões, certificação ou endosso da NASA. Os fundos de rotação não afirmam produtividade, fertilidade ou adequação local.
